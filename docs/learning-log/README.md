# 学習記録

Herdrプラグイン研究で得られた横断的な知見の記録です。

## 構成のルール

- 1 エントリ = 1 ファイル。`YYYY-MM-DD-<slug>.md` というファイル名で作成する。
- ファイル名の日付順に並ぶため、ディレクトリはフラットに保つ。
- 新しいエントリを追加したら、下の表に追記する。
- ファイルが増えて一覧が読みにくくなったら、年ごとのネスト（`2026/` など）を検討する。
